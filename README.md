# Kibble · 今天学一点，闯一关

一个**纯前端单文件**的面试题闯关复习小游戏：答题闯关 → 赚金币 → 养宠物 → 建小城，用游戏化的方式把「背题库」变成「每天想上来玩两关」。

**在线玩：<https://ivy92888-glitch.github.io/kibble/>**

> 本项目名为 "Kibble"，是一个个人学习小游戏，与任何同名或近名的商业产品、商标主体均无关联，非商业用途。

## 核心玩法

1. **闯关答题**：31 本书 / 403 关 / 5021 题（RAG、Python、前端工程化等技术题库），答对赚金币和星星；
2. **记忆曲线复习**：错题自动进入复习队列（1/2/4/7/15 天间隔），像背单词一样循环巩固；
3. **宠物养成**：每天打卡喂食，宠物随累计打卡天数长大（8/31/91 天进化）；
4. **成就系统**：21 枚徽章，按解锁条件自动颁发。

## 技术特点

- 单文件 SPA（index.html 约 6.5MB），零构建、零依赖、离线可玩；
- 进度存 localStorage，纯本地模式，无需注册登录；
- PWA 支持（添加到主屏幕）。

## 数据说明

题库内容为个人学习整理，仅供学习交流使用。
